# 📚 Documentation - Pseudo Code

Bienvenue dans la documentation officielle de **Pseudo Code**, l'application tout-en-un pour maîtriser l'algorithmique et la modélisation de données.

**Pseudo Code** est une application autonome (standalone) conçue pour les étudiants et passionnés d'informatique. Elle offre un environnement de développement complet, interactif et pédagogique.

---

## 🚀 Fonctionnalités Clés

- **🧮 Interpréteur de Pseudo-Code** : Écrivez, testez et déboguez vos algorithmes avec une syntaxe proche du langage naturel.
- **🤖 Assistant IA Intégré** : Profitez de l'aide d'une IA (via Ollama local ou Groq cloud) pour optimiser ou expliquer votre code.
- **📐 Modélisation Merise** : Créez vos MCD, générez automatiquement vos MLD et exportez vos scripts SQL pour MySQL/PostgreSQL.
- **📊 Théorie des Graphes** : Dessinez des graphes, manipulez des sommets et lancez des algorithmes de parcours (BFS, DFS, Dijkstra).
- **📱 Optimisé pour Mobile** : Une interface fluide et adaptée pour apprendre même en déplacement.
