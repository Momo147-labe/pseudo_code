## Format recommandé

- **Format** : PNG avec transparence ou JPG
- **Résolution** : Minimum 1280x720 pour les captures d'écran complètes
- **Ratio** : 16:9 de préférence
- **Poids** : Optimisé (< 500 KB par image)

## Outils suggérés

- **Capture d'écran** : Flameshot, ShareX, Greenshot
- **Édition** : GIMP, Photopea, Figma
- **Annotation** : Excalidraw, Draw.io
