# 📘 Guide général

## Vue d'ensemble de l'application

**Pseudo Code** est un environnement d'apprentissage complet conçu pour maîtriser l'algorithmique et la modélisation de données. Contrairement aux éditeurs classiques, il intègre directement un interpréteur, un assistant IA et des outils de schématisation.

L'application est divisée en trois piliers :
- 🧮 **Algorithmes** : Éditeur avec coloration syntaxique et exécution pas à pas.
- 🗂️ **Merise** : Conception de diagrammes MCD, MLD et MPD.
- 📊 **Théorie des Graphes** : Création et visualisation d'algorithmes sur les graphes.

---

## 🖥️ Interface Utilisateur

### Barre Supérieure
La barre supérieure regroupe les menus principaux :
- **Fichier** : Créer, ouvrir, sauvegarder vos fichiers et changer le thème ou la police.
- **Édition** : Outils classiques de copier/coller et recherche.
- **Exécution** : Boutons pour lancer l'algorithme ou démarrer le débogueur.

### Barre Latérale (Sidebar)
À gauche de l'écran, vous trouverez les onglets de navigation :
- **📁 Explorateur** : Gérer vos fichiers et dossiers locaux.
- **📚 Exemples** : Une bibliothèque de plus de 50 algorithmes et schémas prêts à l'emploi.
- **🏆 Défis** : Relevez des défis classés par difficulté pour gagner des points.
- **🤖 Assistant IA** : Discutez avec l'IA pour obtenir de l'aide sur votre code.

### Zone de Travail
C'est ici que vous écrivez votre code ou dessinez vos schémas. L'application supporte les **onglets multiples**, ce qui vous permet de travailler sur un algorithme et un schéma Merise en même temps.

## ⌨️ Raccourcis Clavier Essentiels

L'application propose des raccourcis pour accélérer votre travail :

| Action | Raccourci |
|--------|-----------|
| **Sauvegarder** | `Ctrl + S` |
| **Exécuter** | `F5` |
| **Pas à pas (Debug)** | `F10` |
| **Rechercher** | `Ctrl + F` |
| **Commenter la ligne** | `Ctrl + /` |
| **Nouvelle ligne (IA)** | `Ctrl + Enter` |

---

## ⚙️ Personnalisation

Vous pouvez personnaliser votre environnement via le menu **Fichier** :
- **Thèmes** : Choisissez entre les modes Clair, Sombre, ou Papier.
- **Police** : Changez la taille de l'écriture ou la famille de police (JetBrains Mono par défaut).
- **Langue** : L'interface s'adapte automatiquement à la langue de votre système.

---

## 💡 Conseils pour l'apprentissage

1. **Utilisez les exemples** : Ne partez pas de zéro ! Importez un exemple pour comprendre comment structurer votre code.
2. **Abusez du Débogueur** : Si votre boucle ne s'arrête pas ou si le résultat est faux, lancez le mode pas à pas pour voir l'évolution des variables en temps réel.
3. **Consultez l'IA** : Si un concept vous échappe (ex: la récursion), demandez à l'assistant IA de vous l'expliquer avec un exemple simple.
