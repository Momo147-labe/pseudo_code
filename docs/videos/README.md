# 🎥 Tutoriels Vidéo

Ce dossier contient tous les tutoriels vidéo de la documentation.

## Structure

- **tutorials/** : Tutoriels pas à pas

## À créer

### Tutoriels à produire

- [ ] `general-overview.mp4` - Présentation générale (15 min)
- [ ] `algo-tutorial.mp4` - Créer et exécuter un algorithme (5 min)
- [ ] `merise-tutorial.mp4` - Créer un MCD et générer le SQL (8 min)
- [ ] `graph-tutorial.mp4` - Créer un graphe et appliquer Dijkstra (10 min)

### Format recommandé

- **Format** : MP4 (H.264)
- **Résolution** : 1920x1080 (Full HD)
- **FPS** : 30 ou 60
- **Codec audio** : AAC
- **Bitrate** : 5-10 Mbps
- **Durée** : 5-15 minutes par tutoriel

## Plan des tutoriels

### 1. Présentation générale (15 min)
1. Introduction (1 min)
2. Installation (2 min)
3. Interface utilisateur (3 min)
4. Exemple d'algorithme (3 min)
5. Exemple de MCD (3 min)
6. Exemple de graphe (3 min)

### 2. Algorithmes (5 min)
1. Créer un nouvel algorithme
2. Écrire le pseudo-code
3. Exécuter en mode pas à pas
4. Analyser la complexité

### 3. Merise (8 min)
1. Créer un MCD avec entités
2. Ajouter des associations
3. Définir les cardinalités
4. Générer le MLD
5. Générer le MPD et le SQL

### 4. Graphes (10 min)
1. Créer un graphe pondéré
2. Ajouter sommets et arêtes
3. Appliquer l'algorithme de Dijkstra
4. Visualiser le résultat
5. Exporter en image

## Outils de création recommandés

### Capture d'écran vidéo
- **OBS Studio** (gratuit, multi-plateforme)
- **SimpleScreenRecorder** (Linux)
- **ShareX** (Windows)

### Montage vidéo
- **DaVinci Resolve** (gratuit, professionnel)
- **Kdenlive** (gratuit, open-source)
- **OpenShot** (gratuit, simple)

### Narration
- **Audacity** (enregistrement audio)
- Microphone de qualité recommandé

## Script type

```
[Intro - 10s]
Bonjour et bienvenue dans ce tutoriel sur [sujet].

[Corps - Variable]

[Démonstration pas à pas]

[Conclusion - 10s]
Vous savez maintenant comment [résumé].
N'hésitez pas à consulter la documentation pour plus d'informations !
```

## Optimisation

Avant d'ajouter les vidéos :
1. Compresser avec HandBrake ou FFmpeg
2. Vérifier la qualité audio
3. Ajouter des sous-titres si possible
4. Tester la lecture sur différents navigateurs

## Hébergement alternatif

Pour des vidéos volumineuses, considérez :
- **YouTube** (lien dans la doc)
- **Vimeo** (qualité professionnelle)
- **Peertube** (open-source)

Dans ce cas, remplacez les liens locaux par des liens YouTube :
```markdown
[![Titre de la vidéo](miniature.png)](https://youtube.com/watch?v=...)
```
